# Enem e ensino superior no Brasil

Projeto final de Programação Orientada a Objetos sobre participação no Enem e acesso e trajetória na graduação. O recorte principal é de 2020 a 2024, com dados públicos do Inep.

## Ambiente

No PowerShell, na pasta do repositório:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

- `src/` guarda o código da aplicação.
- `dados/` guarda os arquivos locais usados na análise.
- `tests/` guarda os testes.

O trabalho é acompanhado pelas [issues do repositório](https://github.com/vienvs/ProjetoFinalPOO/issues). Cada mudança segue em uma branch e um pull request ligado à issue.
